# Images to add

Save these from the Facebook page into this folder, using these exact filenames.
Resize the big ones to about 1600px on the long edge and export as JPEG
around 80% quality, so the page stays fast on a phone.

| Filename | What to use |
|---|---|
| `logo.png` | The circular Glenn's badge from the Facebook profile. PNG with a transparent or white background. |
| `hero-studio.jpg` | Desktop hero. 2400 × 1400 (12:7). Board-and-batten studio exterior. |
| `hero-studio-mobile.jpg` | Mobile hero, swaps in under 820px. 1200 × 1600 (3:4). Door, awning and building corner filling the lower two thirds; upper left kept plain for the headline. |
| `job-studio.jpg` | Interior of the art studio, the shot with the long window and vaulted ceiling. |
| `job-exterior.jpg` | The two-storey house siding job. The after shot, not the before/after split. |
| `job-beams.jpg` | The open living room with the exposed structural beams. Crops to 16:9, so pick a wide one. |
| `jesse.jpg` | Jesse on a jobsite — on a ladder, carrying lumber, looking at something. Not a headshot. Crops to 4:5 (tall), so a vertical shot is ideal. |

Crop ratios the layout uses: first project 3:2 landscape, second 4:5 portrait,
fourth 16:9 wide, then the pattern repeats. Anything you drop in gets cropped to
fit, so choose shots where the subject sits near the centre.

Before any of these go live, confirm with Jesse that the homeowners are fine
with their houses appearing on his website. A Facebook post he made is not the
same as permission to use someone's home in marketing.
